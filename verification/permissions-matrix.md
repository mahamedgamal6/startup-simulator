## 5. الأدلة التفصيلية لكل حساب

### 5.1 `admin` — مدير النظام

- **التنقل:** 9/9 شاشات.
- **بطاقة المنتج:** التكاليف ظاهرة، المحاكي مفعّل، تعديل الهامش مفعّل، إنشاء/تعديل/حذف المنتج ظاهر، 3 أزرار تعديل إكسسوار، تعديل الماكينات ظاهر، وزر طباعة البطاقة الرسمية ظاهر.
- **التحليل المالي:** تعديل عناصر التكلفة ظاهر، ومحاكيان (سعر الخام والهامش) يعملان بـ `input[type=range]` = 2.
- **الإنتاج:** زرّا إدارة الماكينات والإسطمبات ظاهران.
- **الجودة:** 8 أزرار فحص «مطابق» غير معطّلة، و«بدء جولة جديدة» ظاهر.
- **المستخدمون:** إضافة مستخدم ظاهرة، و5 أزرار تعديل، و5 إعادة تعيين كلمة مرور، و4 أزرار حذف. زر حذف الحساب الحالي محجوب لحماية الذات.
- **الأدوار:** إنشاء/استيراد/تصدير المصفوفة ظاهرة، و5 أزرار نسخ، و4 تعديل، و4 حذف. الدور النظامي محمي من التعديل والحذف.
- **السجل:** تصدير CSV مفعّل.
- **مركز البيانات:** 7/7 جداول غير مقفلة، وفيها إضافة/استيراد/تصدير/تعديل/حذف.
- **استعادة البيانات التجريبية:** ظاهرة.

### 5.2 `finance` — المدير المالي

- **التنقل:** 5 شاشات: لوحة القيادة، بطاقة المنتج، التحليل المالي، الجودة، مركز البيانات.
- **بطاقة المنتج:** التكاليف والمحاكي وتعديل الهامش ظاهرة، ومنتج/إكسسوارات قابلة للإدارة، و3 أزرار تعديل إكسسوار، وطباعة رسمية ظاهرة.
- **التحليل المالي:** تعديل عناصر التكلفة ظاهر، ومحاكيان يعملان (2 range).
- **الجودة:** عرض فقط؛ أزرار الفحص معطّلة، و«بدء جولة جديدة» غائب.
- **مركز البيانات:** 7/7 جداول كاملة الصلاحيات.
- **المستخدمون/الأدوار/السجل:** غير موجودة في التنقل.
- **استعادة البيانات التجريبية:** محجوبة؛ يملك `settings.edit` لكنه لا يملك `settings.reset_demo`.
- **الخادم:** كل محاولات إدارة المستخدمين والأدوار والسجل أعادت `FORBIDDEN`.

### 5.3 `exec` — الإدارة العليا

- **التنقل:** 9/9 شاشات، لكن كل عمليات الكتابة محجوبة.
- **بطاقة المنتج:** التكلفة وزرّا الطباعة ظاهران. المحاكي وتعديل الهامش محجوبان برسالة صريحة. إنشاء/تعديل/حذف المنتج غائب، وقسم الإكسسوارات للعرض فقط بلا إضافة أو تعديل، وتعديل الماكينات غائب.
- **التحليل المالي:** لا زر لتعديل عناصر التكلفة، ولا محاكي، ولا هامش؛ عدد المنزلقات = 0، وتظهر رسالتا الحجب.
- **الإنتاج:** زرّا «إدارة الماكينات» و«إدارة الإسطمبات» ظاهران **لكنهما مجرد تنقل**؛ عند الضغط يفتح مركز البيانات على الجدول بوضع عرض فقط: لا إضافة، لا تعديل، لا حذف، لا استيراد.
- **الجودة:** أزرار الفحص معطّلة، و«بدء جولة جديدة» غائب.
- **المستخدمون:** 5 صفوف ظاهرة للعرض فقط، بلا إضافة/تعديل/إعادة تعيين/حذف.
- **الأدوار:** تصدير المصفوفة ظاهر، لكن إنشاء/استيراد/نسخ/تعديل/حذف كلها غائبة.
- **السجل:** تصدير CSV مفعّل، لأن الدور يملك `audit.export`.
- **مركز البيانات:** 7/7 جداول غير مقفلة، وكلها عرض فقط بلا أي إجراء كتابة.
- **الخادم:** قراءة المستخدمين والأدوار والسجل مسموحة، وكل عمليات الكتابة أعادت `FORBIDDEN`.
- **استعادة البيانات التجريبية:** محجوبة.

### 5.4 `production` — مدير الإنتاج

- **التنقل:** 4 شاشات: بطاقة المنتج، الإنتاج، الجودة، مركز البيانات.
- **بطاقة المنتج:** لا تكلفة ولا محاكي ولا إعدادات، ولا منتجات/إكسسوارات قابلة للتحرير. طباعة البطاقة الفنية فقط، دون بطاقة التكلفة. زر تعديل الماكينات داخل البطاقة غائب لأن بوابته `canEditProduct`.
- **الإنتاج:** إدارة الماكينات وإدارة الإسطمبات ظاهرتان، ويستطيع إنشاء/تعديل الماكينات والإسطمبات.
- **الجودة:** عرض فقط؛ الفحص معطّل، وبدء الجولة غائب.
- **مركز البيانات:**
  - المنتجات: عرض فقط.
  - الخامات: عرض فقط.
  - الإكسسوارات: **مقفل**.
  - الإسطمبات: عرض + إنشاء + تعديل، بلا استيراد/تصدير/حذف.
  - الماكينات: عرض + إنشاء + تعديل + استيراد، بلا تصدير/حذف.
  - التعبئة: عرض فقط.
  - عناصر التكلفة: **مقفل**.
- **الخادم:** كل عمليات إدارة النظام أعادت `FORBIDDEN`.
- **استعادة البيانات التجريبية:** محجوبة.

### 5.5 `quality` — مشرف الجودة

- **التنقل:** 3 شاشات: بطاقة المنتج، الجودة، مركز البيانات.
- **بطاقة المنتج:** بلا تكاليف، وبلا إدارة منتج أو إكسسوار، وطباعة فنية فقط. زر تعديل الماكينات غائب.
- **الجودة:** 8 أزرار فحص «مطابق» مفعّلة، و«بدء جولة جديدة» ظاهر، وطباعة البطاقة الفنية ظاهرة.
- **مركز البيانات:**
  - المنتجات، الخامات، الإسطمبات، التعبئة: عرض فقط.
  - الإكسسوارات، الماكينات، عناصر التكلفة: **مقفلة**.
- **الخادم:** كل عمليات إدارة النظام أعادت `FORBIDDEN`.
- **استعادة البيانات التجريبية:** محجوبة.

## 8. الملاحظات والاستنتاج

### ما تم إثباته

- كل حساب يرى فقط الشاشات المصرّح بها في التنقل، ولا توجد شاشة إدارية ظاهرة لدور لا يملك صلاحيتها.
- أزرار الكتابة (إضافة/تعديل/حذف/استيراد/إعادة تعيين/نسخ) تختفي أو تتعطّل حسب الصلاحية في كل الشاشات المفحوصة.
- التكاليف والمحاكي والهامش محجوبة عن الإنتاج والجودة، ومقيّدة عن الإدارة العليا، وظاهرة للمدير والمالي فقط.
- الجداول السبعة تحترم `data.<table>.<action>`: قفل كامل، عرض فقط، أو صلاحيات جزئية.
- الخادم يفرض صلاحيات المستخدمين والأدوار والسجل بشكل مستقل عن الواجهة؛ لا يمكن للإدارة العليا أو المالي أو الإنتاج أو الجودة تنفيذ كتابة إدارية عبر RPC.
- حماية الذات (منع حذف الحساب الحالي) وحماية الدور النظامي تعملان في الواجهة.

### ملاحظة UX غير أمنية

- الإدارة العليا ترى زرّي «إدارة الماكينات» و«إدارة الإسطمبات» في شاشة الإنتاج رغم أنها للعرض فقط. الضغط يفتح مركز البيانات بوضع عرض فقط، ولا تظهر أي أزرار كتابة. التسمية مضللة ويمكن تحسينها إلى «عرض الماكينات/الإسطمبات» أو ربط ظهور الزرين بصلاحية إنشاء/تعديل.

### قيود يجب عدم إخفاؤها

- **بيانات المصنع المحلية ليست محمية خادميًا.** أي مستخدم يستطيع تعديل `localStorage` أو استدعاء منطق الواجهة يمكنه تجاوز بوابات العرض لهذه البيانات. هذا مقبول كنسخة تجريبية أحادية المتصفح، لكنه لا يكفي كضمان أمني متعدد المستخدمين.
- الاختبار أثبت الصلاحيات والعمليات الإدارية، ولم يُجرِ اختبار اختراق أو مراجعة أمنية شاملة لكلمات المرور/الجلسات.
- لم تُعدّل أي شاشة أو صلاحية أثناء هذا الاختبار؛ التغيير الوحيد هو إضافة ملفات الأدلة هذه.
